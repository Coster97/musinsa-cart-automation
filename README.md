# 무신사 장바구니 E2E 테스트 자동화

Playwright와 TypeScript를 활용하여 무신사 장바구니의 핵심 사용자 시나리오를 자동화한 E2E 테스트 프로젝트입니다.

실제 사용자 관점에서 장바구니 진입, 상품 선택, 옵션 변경, 쿠폰 적용, 구매 금액 계산, 주문서 이동까지 주요 흐름을 기반으로 테스트를 구성하였으며, 반복적으로 수행되는 회귀 테스트를 자동화하여 테스트 효율성과 유지보수성을 높였습니다.

또한 테스트 실행에 필요한 상품을 추천 상품 영역에서 선택하고, 상품별 옵션을 자동으로 선택하여 장바구니에 담는 사전 데이터 세팅 과정까지 자동화했습니다. 이를 통해 테스트 시작 전 장바구니 상태를 수동으로 준비해야 하는 과정을 줄이고, 필요한 테스트 환경을 자동으로 구성할 수 있도록 했습니다.

단순 UI 동작 확인에 그치지 않고 상품 옵션·수량 변경, 쿠폰 할인 적용, 구매 금액 계산 등 사용자 동작에 따른 금액 정합성까지 함께 검증하도록 구현했습니다.

> ⚠️ 본 프로젝트는 개인 학습 및 포트폴리오 목적으로 작성되었습니다.  
> 실제 서비스 환경을 대상으로 테스트를 수행하므로 테스트 계정이 필요하며, 저장소에는 개인 계정 정보 및 민감한 데이터가 포함되어 있지 않습니다.

## 프로젝트 특징

- Page Object Model(POM)을 적용하여 페이지별 Locator와 Action을 분리
- `test.step`을 활용하여 테스트 단계를 시나리오 단위로 구성
- Helper를 활용하여 테스트 실행 전 필요한 상품 세팅 과정 자동화
- 상품별 옵션 개수와 구성에 따라 선택 가능한 옵션을 자동으로 선택
- 테스트 데이터 준비부터 기능 검증까지 하나의 E2E 흐름으로 구성
- 상품 옵션·수량 변경에 따른 금액 계산 검증
- 쿠폰 할인 금액 및 구매 금액 데이터 정합성 검증
- Playwright HTML Report 지원
- 실행 로그를 통해 각 테스트 단계의 수행 결과 확인

## 실행 전 준비사항

### 계정 및 로그인

- 테스트 시작 시 로그아웃 상태여야 합니다.
- 로그인 페이지에서 Playwright가 `page.pause()` 상태로 대기합니다.
- 원하는 방법으로 로그인한 뒤 장바구니 페이지로 정상 리다이렉트되면 Playwright Inspector의 **Resume(▶)** 버튼을 눌러 테스트를 이어서 진행합니다.

### 테스트 데이터

테스트에 필요한 장바구니 상품은 테스트 실행 과정에서 자동으로 세팅됩니다.

- 장바구니 추천 상품 영역에서 테스트용 상품을 선택합니다.
- 상품 상세 페이지에서 선택 가능한 옵션을 자동으로 선택합니다.
- 선택한 상품을 장바구니에 담은 뒤 다시 장바구니 페이지로 이동합니다.
- 동일한 과정을 반복하여 테스트에 필요한 상품을 장바구니에 구성합니다.

따라서 테스트 실행 전에 장바구니에 상품을 직접 담아둘 필요는 없습니다.

단, 실제 서비스 환경의 데이터를 사용하는 특성상 추천 상품의 판매 상태, 옵션 제공 여부, 쿠폰 제공 여부 등에 따라 테스트 결과가 영향을 받을 수 있습니다.
