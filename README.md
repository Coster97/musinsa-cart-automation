# Musinsa Cart E2E Automation

Playwright(TypeScript)를 활용하여 무신사 장바구니의 핵심 사용자 시나리오를 자동화한 프로젝트입니다.

- 약 180개의 장바구니 테스트 케이스 중 반복 수행 및 회귀 검증 가치가 높은 핵심 시나리오를 선별하여 자동화하였습니다.
- Page Object Model(POM)을 적용하여 페이지별 Locator와 동작을 분리하고 유지보수성을 고려한 구조로 구성하였습니다.
- 상품 옵션·수량 변경, 쿠폰 적용, 구매 금액 계산 등 단순 UI 동작뿐 아니라 데이터 정합성 검증을 포함하였습니다.

## 실행 전 준비 사항

본 테스트는 실제 서비스 환경을 대상으로 하며, 안정적인 테스트 수행을 위해 아래 사전 조건이 필요합니다.

### 계정 및 로그인

- 테스트 시작 시 로그아웃 상태여야 합니다.
- 테스트 진행 중 로그인 페이지에서 Playwright가 `page.pause()` 상태로 대기합니다.
- 로그인 화면에서 원하는 방법으로 직접 로그인을 완료합니다.
- 로그인 완료 후 장바구니 페이지로 정상 리다이렉트된 것을 확인한 뒤 Playwright Inspector의 **Resume(▶)** 버튼을 선택하여 테스트를 계속 진행합니다.

### 장바구니 테스트 데이터

테스트 실행 전 로그인할 계정의 장바구니를 아래 상태로 준비합니다.

- 장바구니에 상품을 **2개 이상** 담아둡니다.
- 전체 선택 체크박스는 **비활성화(미선택)** 상태로 준비합니다.
- 브랜드 그룹 선택 및 선택 삭제 테스트가 가능하도록 서로 구분 가능한 상품을 구성합니다.
- 옵션 변경이 가능한 상품을 포함합니다.
- 수량 변경이 가능한 상품을 포함합니다.
- **최저가 도전 상품이 아닌 상품**을 포함합니다.
- **사용 가능한 상품 쿠폰이 존재하는 상품**을 포함합니다.
- 쿠폰 적용 후 할인 금액을 검증할 수 있는 상품을 사용합니다.

### 테스트 수행 시 참고사항

- 테스트 과정에서 선택된 상품 또는 브랜드 그룹이 실제 장바구니에서 삭제될 수 있습니다.
- 좋아요 상태가 테스트 실행 전 상태와 반대로 변경됩니다.
- 상품 옵션 및 수량이 실제 장바구니에 변경된 상태로 저장될 수 있습니다.
- 쿠폰이 실제 상품에 적용될 수 있으므로 반복 실행 시 장바구니 상태를 다시 확인해야 합니다.
- 상품 가격, 할인율, 쿠폰 및 프로모션은 서비스 정책에 따라 변경될 수 있으므로 테스트 실행 전 대상 상품 상태를 확인합니다.
